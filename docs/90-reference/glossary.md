# Glossary

| Term | Meaning |
|---|---|
| **AHPRA** | Australian Health Practitioner Regulation Agency — registers health practitioners |
| **AIR** | Australian Immunisation Register |
| **AMT** | Australian Medicines Terminology |
| **ASL** | Active Script List — a patient's electronic prescriptions held centrally |
| **ATSI** | Aboriginal and/or Torres Strait Islander |
| **AUSDRISK** | Australian Type 2 Diabetes Risk Assessment Tool |
| **BBPIP** | Bulk Billing Practice Incentive Program — from 1 Nov 2025; 12.5% loading for practices bulk billing 100% of eligible services |
| **CTP** | Compulsory Third Party — motor vehicle accident insurance |
| **DNA** | Did Not Attend |
| **DVA** | Department of Veterans' Affairs |
| **eScript** | Electronic prescription, delivered by token or via the ASL |
| **FRACGP** | Fellow of the Royal Australian College of General Practitioners |
| **GPCCMP** | GP Chronic Condition Management Plan — replaced GPMP/TCA on 1 July 2025 (MBS 965/967) |
| **GPMHSC** | General Practice Mental Health Standards Collaboration — accredits Mental Health Skills Training |
| **GPMP** | GP Management Plan (MBS 721) — replaced 1 July 2025 |
| **HPI-I / HPI-O** | Healthcare Provider Identifier — Individual / Organisation |
| **HPOS** | Health Professional Online Services |
| **IHI** | Individual Healthcare Identifier |
| **IRN** | Individual Reference Number — the number beside a name on a Medicare card |
| **KFP** | Key Feature Problems — an RACGP Fellowship exam |
| **MBS** | Medicare Benefits Schedule |
| **MHST** | Mental Health Skills Training — gates MBS items 2715/2717 |
| **Minor ID** | Medicare Minor Customer ID, used for claiming and banking, per location |
| **MyMedicare** | Voluntary patient registration with a single practice |
| **NIP** | National Immunisation Program |
| **PBS** | Pharmaceutical Benefits Scheme |
| **PIP / WIP** | Practice Incentives Program / Workforce Incentive Program |
| **PRODA** | Provider Digital Access — government authentication for providers |
| **RACF** | Residential Aged Care Facility |
| **RACGP** | Royal Australian College of General Practitioners |
| **Recall** | Practice-initiated follow-up for a clinically significant matter — there is a duty to pursue it |
| **Red Book** | RACGP Guidelines for preventive activities in general practice |
| **Reminder** | Population-health prompt (screening, immunisation) — no equivalent duty |
| **Registrar** | A doctor in GP training |
| **RTPM** | Real-Time Prescription Monitoring — SafeScript (VIC/NSW), QScript (QLD), ScriptCheckSA, NTScript |
| **S4 / S8** | Schedule 4 (prescription only) / Schedule 8 (controlled drug) medicines |
| **TCA** | Team Care Arrangements (MBS 723) — replaced 1 July 2025 |
| **Vocational registration** | Recognition as a specialist GP; gates the higher MBS fee tier |
